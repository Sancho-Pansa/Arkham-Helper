# Arkham Helper
You are an experienced Android app developer.

This project is an attempt to implement character sheets for old tabletop game "Arkham Horror". 
This game has a lot of concurrent mechanics, counters and rules, which must be observed by players,
which can become especially difficult if the player is a newbie, or at a late game stage.

This project consists of two main parts:
- "Core" is a game logic. It is my attempt to transfer game elements in OOP style in Java programming language.
- "Android" is a subproject for Mobile application.

I will later add more specific information about subprojects in the corresponding AGENTS.md.
